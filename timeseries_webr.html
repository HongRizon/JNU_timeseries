주 자료(BTC 일별 거래 횟수)에는 어떤 특징이 있고, 대조 자료(QQQ 월말 종가)와는 무엇이 다른가?

시계열자료 {Xt ∣ t = 1, ⋯, n}는 시간의 흐름에 따라 관측된 자료이고, 확률변수들의 모임인 확률과정 {Xt ∣ t ∈ T}의 실현된 값(표본경로)이라서 하나의 시간에 하나의 값만 관측되고 관측값들 사이에 '관계'가 있다. 시계열분석은 자료의 생성 구조(추세, 계절성, 불규칙변동)를 서술하고 그 관계로 미래값을 예측한다. 분해법·평활법·ARMA 모형·회귀모형 어느 것이든 먼저 그림을 그려 특징을 읽는다.

과거로 바로 예측하기: 평활법




주 자료의 과거값들을 가중평균하면 다음 날(2025년 10월 6일)의 거래 횟수는 얼마로 예측되나?


평활법은 과거값들의 가중평균으로 변동을 줄여 패턴을 파악하고 미래값을 예측한다. 이동평균법은 최근 m개 값에 같은 가중치를 주고, 지수평활법은 과거로 갈수록 지수적으로 낮은 가중치를 준다. 지수평활법은 추세와 계절성이 없을 때는 단순지수평활법, 있을 때는 Holt-Winters 방법을 쓴다.

ACF




정상시계열의 자기상관함수(ACF)는 ρh = Corr(Xt, Xt+h) = γh / γ0이고, γh = Cov(Xt, Xt+h)는 자기공분산함수다 (ρ0 = 1). 쌍 (X1, X1+h), ⋯, (Xn−h, Xn)을 이용해 표본자기상관함수(sample ACF) ρ̂h = Σ(Xt − X̄)(Xt+h − X̄) / Σ(Xt − X̄)²로 추정한다. 시차 h에 따라 ρ̂h를 그린 그림이 correlogram이다. Bartlett(1946)에 따르면 X1, ⋯, Xn이 i.i.d.(서로 독립이고 분포가 같음)일 때 ρ̂h ≈ N(0, 1/n)이므로 P(ρ̂h ∈ (−1.96/√n, 1.96/√n)) ≈ 0.95다. 그림의 파란색 점선이 ±1.96/√n이고, ρ̂h가 점선 안에 있으면 H0: ρh = 0을 기각할 수 없다.


정상시계열의 ACF는 시차가 커질수록 지수적으로 급격히 감소하고, 비정상시계열의 ACF는 1에서 천천히 감소한다. 주기 길이의 시차에 peak가 있으면 그 주기의 계절성이다. acf() 그림의 가로축 1은 ts()의 한 주기(freq)다. 주 자료는 freq=7이라 가로축 1이 7일이고, cor()로 구한 시차 1 상관(인덱스 한 칸 = 1일)과 단위가 다르다.

그림과 ACF로 분명하지 않을 때는 단위근 검정으로 정상성을 통계적으로 판단한다. 단위근이 있는 시계열은 확률보행(U5)처럼 충격이 쌓여 비정상이다. ADF 검정은 단위근 존재(unit root)가 귀무가설이고, 결정적 추세를 포함하여 단위근 여부를 검정한다. KPSS와 ADF는 귀무가설이 반대이므로 함께 써서 판단한다.

백색잡음




백색잡음은 ① E(Xt) = 0 ② Var(Xt) = σ² < ∞ ③ Corr(Xt, Xs) = 0 (t ≠ s)인 시계열이고, WN(0, σ²)로 적는다. 평균과 분산이 t에 무관하고 다른 시점의 값과 상관이 없으므로 정상시계열이다. 확률보행과 AR 모형은 이 백색잡음을 오차항 εt로 써서 만든다.


rnorm(200, 0, 5)는 평균 0, 표준편차 5인 정규난수 200개다. 서로 독립이므로 백색잡음이다. ACF의 점선은 ±1.96/√n, 곧 상관이 0일 때 ρ̂h가 들어가는 약 95% 범위다.

AR(p) 모형은 Xt = φ1Xt−1 + ⋯ + φpXt−p + εt, εt ~ WN(0, σ²)이고, φ1, ⋯, φp는 자기회귀계수다. 특성방정식 φ(x) = 1 − φ1x − ⋯ − φpxp = 0의 모든 해의 절대값이 1보다 크면(해가 단위원 밖에 있으면) 정상이다. AR(1)은 Xt = φXt−1 + εt이고 해가 x = 1/φ이므로 정상성 조건은 ∣φ∣ < 1이다. φ = 1이면 확률보행과 같아 비정상이다.

추정과 유의성 검정




추정은 잠정모형의 모수를 자료에서 구하는 단계다. 평균이 μ인 AR(p)는 Xt − μ = φ1(Xt−1 − μ) + ⋯ + φp(Xt−p − μ) + εt이고, 추정할 모수는 μ, φ1, ⋯, φp, σ²다. 풀어 쓰면 Xt = c + φ1Xt−1 + ⋯ + φpXt−p + εt, c = (1 − φ1 − ⋯ − φp)μ이고 E(Xt) = μ다. ar()는 Yule-Walker 추정을 쓴다. Yule-Walker 방정식은 ACF와 모수의 관계식이고, 여기에 표본 ACF를 넣어 φ̂를 구한다. AR(1)이면 ρh = φρh−1이라 φ̂ = ρ̂1이다. 최대우도추정(MLE)과 최소제곱추정(OLS)도 있다. 차수는 AIC(적합도에 모수 개수의 벌점을 더한 값으로, 작을수록 좋다)가 가장 작은 것을 고른다.


진단의 첫 도구는 모수의 유의성 검정이다. H0: φi = 0의 검정통계량은 φ̂i / se(φ̂i)이고, 절대값이 크면(대략 1.96보다 크면) H0를 기각하여 H1: φi ≠ 0으로 본다. ar(X)$asy.var는 추정량의 점근 분산행렬이라, 대각원소의 제곱근이 표준오차 se(φ̂i)다.
