도입 카드 1: 시계열자료 (p.2–3)

  • 확률과정 {Xt ∣ t ∈ T}는 확률변수들의 모임이다. T = (−∞, ∞)이면 연속형, T = {0, ±1, ±2, ⋯}이면 이산형이다.

이론 카드: 이동평균법과 지수평활법 (p.2–7)
  • 이동평균법 (p.2): X^t+1 = (Xt + Xt−1 + ⋯ + Xt−m+1) / m. 과거값들에 동일한 가중치를 적용한다. ※ 1장에서 추세 추정에 쓴 것은 중심 이동평균이고, 3장 예측에 쓰는 단측 이동평균과는 다르다.

이론 카드: i.i.d.와 정상성 (p.2–6)
  • i.i.d. vs 시계열 (p.2–5): X1, ⋯, Xn ~ i.i.d.(independently identically distributed: 서로 독립이고 분포가 같은) f(x)이면 관심의 대상 f(x)를 x1, ⋯, xn으로 대략 추정할 수 있다. 시계열의 관심 대상은 f1(x), ⋯, fn(x)와 변수들 간의 관계(dependency)다. "시계열자료는 표본경로가 하나뿐이다" (p.3).
  • 정상성 (p.6): 시계열의 확률적인 성질들이 시간의 흐름에 따라 불변함(time-invariant). 조건은 ① E(Xt) = μ ② Var(Xt) = σ² (둘 다 시점 t에 관계없이 동일) ③ Corr(Xt, Xt+h) = ρh (시점 t에 관계없이 시차 h에만 의존).
  • Corr(X, Y) = 0이면 X, Y는 uncorrelated. 강(strictly) 정상성 조건은 f(Xt1, ⋯, Xtn) = f(Xt1+h, ⋯, Xtn+h).

이론 카드: ACF와 correlogram (p.10–15)
  • 자기상관함수 ACF (p.10–11): 정상시계열에 대하여 ρh := Corr(Xt, Xt+h) = E(Xt − μ)(Xt+h − μ) / (√Var(Xt)·√Var(Xt+h)) = γh / γ0, ρ0 = 1. γh := Cov(Xt, Xt+h)는 자기공분산함수다. Xt와 Xt+h의 결합분포를 알아야 계산할 수 있다.
  • 추정 (p.11): ρ = Corr(X, Y) = E(X − μX)(Y − μY) / (√Var(X)·√Var(Y))는 (X1, Y1), ⋯, (Xn, Yn)을 이용해 ρ^ = Σ(Xi − X¯)(Yi − Ȳ) / (√Σ(Xi − X¯)²·√Σ(Yi − Ȳ)²)로 추정한다. ρh는 (X1, X1+h), ⋯, (Xn−h, Xn)을 이용해 표본자기상관함수(sample ACF) ρ^h = Σ(Xt − X¯)(Xt+h − X¯) / Σ(Xt − X¯)²로 추정한다.
  • correlogram (p.12–15): 시차 h에 따라 ρ^h를 그린 그림. Barlett(1946): X1, ⋯, Xn ~ i.i.d.일 때 ρ^h ≈ N(0, 1/n)이므로 P(ρ^h ∈ (−1.96/√n, 1.96/√n)) ≈ 0.95. ρ^h가 파란색 점선 안에 있으면 H0: ρh = 0을 기각할 수 없다.
  • 정상 시계열의 ACF는 시차가 커질수록 지수적으로 급격히 감소하고, 비정상 시계열은 1에서 천천히 감소한다 (예시 그림 p.14–15).

이론 카드 1 (p.24–33)
  • 평균이 μ인 AR(p) (p.24): Xt − μ = φ1(Xt−1 − μ) + ⋯ + φp(Xt−p − μ) + εt, 또는 Xt = c + φ1Xt−1 + ⋯ + φpXt−p + εt, c = (1 − φ1 − ⋯ − φp)μ. E(Xt) = μ이고, Var(Xt)와 Corr(Xt, Xt+h)는 AR(p)와 같다.
  • ACF만으로 차수 맞히기 (p.26–28, 강의 그림): AR(p)에서 생성한 자료 두 개의 그림과 ACF를 먼저 보고 (p.26), 정답 AR(1): Xt = 0.5Xt−1 + εt와 AR(3): Xt = 0.1Xt−1 + 0.3Xt−2 + 0.2Xt−3 + εt를 확인한 뒤 (p.27), PACF를 더해 차수만큼 튀는 막대를 확인한다 (p.28).

이론 카드 (p.10–12, p.26–28)
  • OLS와 GLS (p.11): Yi = β0 + β1xi + εi에서 (β^0ols, β^1ols) = argmin Σ(Yi − (β0 + β1xi))². εi ~ i.i.d.(0, σ²)이면 OLS는 BLUE (Best Linear Unbiased Estimator). GLS는 오차항의 가정이 만족되도록 자료를 선형변환한 후 OLS를 사용하며, 오차항의 가정이 만족되지 않을 때 OLS보다 더 효율적이고, 오차항에 대한 정보가 필요하다 (예: εi ~ AR(2)).
  • 잠정모형과 최종모형의 꼴 (p.10, p.12): Xt = β0 + β1t + εt, εt = φ1εt−1 + φ2εt−2 + ηt, ηt ~ WN. 강의 예 (기온 직선 추세): 잠정모형 β^0 = −34.92, β^1 = 0.02, φ^1 = 0.51, φ^2 = 0.29 (p.10) → GLS 최종모형 β^0 = −33.33, β^1 = 0.017, φ^1 = 0.515, φ^2 = 0.30 (p.12).
  • 예측 두 가지 (p.26): 시계열모형 기반의 예측은 predict(fit, n.ahead=12), 회귀모형 기반의 예측은 predict(fit, new.X)다. fit의 결과를 이용하여 설명변수 new.X에 대한 예측값을 출력한다.
  • 역변환과 편향 보정 (p.28): log(Xt) = f(t) + εt에서 E(εt) = 0이므로 log(Xt)의 예측은 f^(t)이다. 그러면 X^t = ef^(t)일까? Xt = ef(t)+εt = ef(t)eεt이므로 E(eεt) = 1이면 X^t = ef^(t)지만, εt ~ N(0, σ²)일 때 E(eεt) = eσ²/2 ≠ 1이다. 따라서 X^t = ef^(t)eε^t, eε^t = (1/n)Σt=1n ert (correction term, rt는 잔차).
