사용법

무엇어떻게
R 준비페이지를 열면 브라우저 안에서 R(webR)을 준비한다 (10–30초, 인터넷 필요). 오른쪽 위가 'R 준비됨'으로 바뀌면 셀을 실행할 수 있다.
셀 실행셀의 ▶ 실행 단추, 또는 코드 상자 안에서 Ctrl+Enter (Mac은 ⌘+Enter). 결과와 그림은 셀 바로 아래에 나온다.
바꿔 보기# 바꿔 보기라고 적힌 줄의 값만 바꿔 다시 실행한다. ↺ 단추는 코드를 처음 상태로 되돌린다.
자료TRD(주 자료)와 QQQ(대조 자료)는 R을 준비할 때 미리 읽혀 있다. 어떤 화면에서든 바로 쓸 수 있다.
앞 셀모든 셀은 R 세션 하나를 같이 쓴다. 앞 셀이 만든 변수를 쓰는 셀을 먼저 누르면 필요한 앞 셀을 자동으로 먼저 실행하고, 그 사실을 출력 맨 위에 적는다.
패키지tseries·forecast·nlme를 쓰는 셀은 처음 실행할 때 패키지를 내려받는다 (한 번만, 수십 초).
질문셀 앞의 질문은 실행하기 전에 예상해 보고, 셀 뒤의 질문은 결과를 보고 답한 뒤 '답'을 눌러 맞춰 본다.
R 초기화위쪽의 'R 초기화'는 변수를 모두 지우고 두 자료만 다시 읽는다. 결과가 이상하면 누른 뒤 셀을 다시 실행한다.
넘기기화면 아래의 ◀ ▶ 단추, 키보드 ← →, 위쪽의 단원 단추, '목록'.
기록빈칸 표와 기록 칸에 쓴 내용은 이 브라우저에 저장되고, 마지막 화면에서 텍스트 파일로 내려받을 수 있다.

RStudio에서 쓰려면

자료 파일을 받아 작업 폴더에 두면 모든 셀의 코드를 그대로 쓸 수 있다. 먼저 아래 네 줄로 자료를 읽는다.

DAT <- read.table("trd.txt", header=TRUE)
TRD <- ts(DAT[,1], start=c(1,1), freq=7)
QQ <- read.table("qqq.txt", header=TRUE)
QQQ <- ts(QQ[,1], start=c(1999,4), freq=12)
